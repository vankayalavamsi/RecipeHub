# 🍳 RecipeHub

> **Discover recipes. Explore new flavors. Cook something delicious.**

RecipeHub is a modern recipe discovery web application built with **React** and **Vite**. It provides a clean and responsive interface for exploring recipes and navigating through different sections of the application.

🔗 **Live Demo:** [recipehub23.netlify.app](https://recipehub23.netlify.app/)
📦 **Repository:** [github.com/vankayalavamsi/RecipeHub](https://github.com/vankayalavamsi/RecipeHub)

---

## ✨ Features

* 🍽️ **Recipe Discovery**
  Browse and explore a collection of recipes through a simple, intuitive interface.

* 🔎 **Easy Navigation**
  Navigate between different pages and recipe sections using React Router.

* 📱 **Responsive UI**
  Designed to provide a smooth experience across desktop, tablet, and mobile screens.

* 🎨 **Modern Interface**
  Clean layouts and reusable UI components for a consistent experience.

* ⚡ **Fast Performance**
  Powered by Vite for fast development and optimized production builds.

* 🧩 **Reusable Components**
  Built with React components to keep the application modular and maintainable.

| Technology       | Purpose                           |
| ---------------- | --------------------------------- |
| ⚛️ React         | Building the user interface       |
| ⚡ Vite           | Development server and build tool |
| 🧭 React Router  | Client-side routing               |
| 🖼️ Lucide React | UI icons                          |

## 🚀 Getting Started

Follow these steps to run RecipeHub locally.

### 1. Clone the repository

```bash
git clone https://github.com/vankayalavamsi/RecipeHub.git
```

### 2. Navigate to the project

```bash
cd RecipeHub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The Vite development server will provide a local URL, typically:

```text
http://localhost:5173
```

Open the URL in your browser to start exploring RecipeHub.
